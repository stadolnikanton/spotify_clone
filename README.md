# Spotify Clone

Клон музыкального сервиса с возможностью воспроизведения треков и авторизацией.

## Особенности
* Воспроизведение музыки (Web Player)
* Регистрация и вход пользователей
* Красивый интерфейс (Custom CSS)

## Запуск проекта

1. Установка:
   uv sync

2. Миграции БД:
   alembic upgrade head

3. Старт:
   python main.py
